Tokenizer data embedded in libqwen_image.so
-------------------------------------------
The native library includes the following tokenizer resources through
stable-diffusion.cpp. The embedded copies contain extracted or reformatted data.

CLIP BPE merge table
The SDK embeds the subset of OpenAI's CLIP merge table published for ViT-L/14.
Sources: https://github.com/openai/CLIP and
https://huggingface.co/openai/clip-vit-large-patch14/blob/main/merges.txt

Apache-2.0 tokenizer data
The following resources are distributed under the Apache License, Version 2.0.
A copy of the license is included in LICENSES/Apache-2.0.txt.

- Qwen2-family BPE merge table by the Qwen Team. The table matches the one
  published for Qwen2.5-VL and Qwen3-VL.
  https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/blob/main/merges.txt
  https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct/blob/main/merges.txt
- Tekken vocabulary and merge table from Mistral AI's Mistral Small 3.1.
  https://huggingface.co/mistralai/Mistral-Small-3.1-24B-Instruct-2503/blob/main/tokenizer.json
- T5 and UMT5 unigram tokenizer data from Google. The embedded T5 vocabulary
  matches the published T5 vocabulary. The UMT5 copy represents the Unicode
  line and paragraph separator tokens as empty strings.
  https://huggingface.co/google-t5/t5-base/blob/main/tokenizer.json
  https://huggingface.co/google/umt5-xxl/blob/main/tokenizer.json
- gpt-oss vocabulary and merge table from OpenAI.
  https://huggingface.co/openai/gpt-oss-20b/blob/main/tokenizer.json

Gemma 2 and Gemma 3 tokenizer data
The SDK embeds vocabulary and BPE merge tables extracted from Google LLC's
Gemma 2 and Gemma 3 tokenizers. The tables were converted into embedded data
with escaped characters in the merge rules.
Sources: https://huggingface.co/google/gemma-2-2b-it and
https://huggingface.co/google/gemma-3-12b-it
